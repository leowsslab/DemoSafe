# DemoSafe 操作指南

DemoSafe 是本機錄屏文字檢查與遮罩原型。第一版使用 CPU，尚未完成 UGen300 實機驗證。

## 啟動

在專案資料夾執行 scripts/start.ps1；腳本會自動開啟已授權的本機瀏覽器工作階段，不需要另外註冊帳號。不要只手動輸入網址，因為新的瀏覽器尚未取得本次啟動的授權。
伺服器每次重啟都會換新憑證；看到「Local session required」時，重新透過啟動腳本開啟。請勿分享啟動時的私人連結。
首次安裝需要 Python 3.12 與網路：執行 scripts/setup.ps1 -PythonExecutable <python.exe 路徑>。
模型隨 RapidOCR 套件安裝，執行 OCR 不呼叫雲端 API。

## 操作

1. 選取內附示範或匯入自己的 PNG/JPEG/MP4。
2. 如需檢查客戶代碼等文字，在自訂關鍵字欄每行填一項。
3. 等待分析完成。點選問題項目，查看時間、類型及位置。
4. 勾選需要遮罩的項目；必要時手動補框並指定開始與結束時間。
5. 匯出。系統以黑色實心遮罩寫入新檔，移除原音訊，再執行一次 OCR 檢查。
6. 播放輸出，檢查是否遮住預期資訊，再下載結果和不含原始敏感字串的 JSON 報告。
7. 需要清除資料時，按 Delete review 並確認；這會刪除 App 工作資料夾中的原片副本、預覽、匯出與報告，不影響你電腦其他位置的來源檔。工作程序實際結束前不可刪除，取消後也可能需要稍候。

選取摘要會分列自動發現、選定遮罩、人工遮罩與保留項目；沒有選取的發現會留在輸出中。若匯出後變更選取或人工框，必須再次匯出，舊輸出不會自動更新。

## 適用範圍

最多 60 秒、1920×1080、30 fps、100 MB 的固定影格率影片；建議 H.264 MP4。PNG/JPEG 最高 1920×1080。
影片時間戳若變動或無法可靠取得，會拒絕處理，請先轉為固定影格率。
辨識範圍是英數 Email、限定格式電話、明確憑證文字與自訂關鍵字。
不辨識所有人名、住址、人臉或語音。新影片預設無聲。
原始檔和分析結果留在本機，錄屏上傳是送到本機服務。
若 OCR 看錯、字太小、壓縮失真或文字模糊，可能漏判。零個輸出發現不是隱私保證。
再次檢查使用相同 OCR，不能取代人工覆核。
H.264 匯出使用 CRF 0，優先保留文字與遮罩邊界；輸出檔案可能較大。

## 參賽與公開

此儲存庫提供 CPU 原型與受控測試證據。建立儲存庫不代表已完成競賽投稿；影片連結由實際上傳結果補入。
初賽展示必須標示CPU；未接到UGen300前不得宣稱實機速度或功耗。
自建畫面和樣本中的資料都是虛構，不代表真實客戶採用或市場驗證。
