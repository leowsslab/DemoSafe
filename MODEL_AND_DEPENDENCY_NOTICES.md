## FFmpeg executable

The installed `imageio-ffmpeg` package resolves to `ffmpeg-win-x86_64-v7.1.exe`. Running that exact executable with `-L` reports **GPL version 3 or later**. The BSD license of the Python wrapper does not change the executable's license. DemoSafe invokes it as a separate process and uses its `libx264` encoder. The [FFmpeg legal page](https://ffmpeg.org/legal.html) explains that its license depends on enabled components.

The source submission does not bundle this executable or `.venv`. Package installation supplies it. Any future binary redistribution must retain the appropriate FFmpeg license and corresponding-source arrangements for the exact build; do not label the complete binary bundle as BSD or Apache solely because the wrapper uses that license.
